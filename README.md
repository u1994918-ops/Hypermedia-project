# Marcel Alemany Blasco — Personal Portfolio
1. User profile
The final users are recruiters, professors and potential collaborators who want to learn about me as a Computer Engineering student at the Universitat de Girona. They expect to find a clear introduction, examples of my academic work, my technical skills and some personal background.

My user persona is a IT company recruiter looking for students for a software development internship. They have limited time and needs to understand what I study, which tools I use and how I approach a project. The website helps them explore my work quickly and read more when something catches their attention.

2. Information architecture
The website uses a single-page structure. Its sections follow a simple order so visitors can understand who I am, explore my work and learn more about my interests. The header contains my name and three navigation links: Work, Skills and About. These links move directly to the corresponding sections without opening another page.

The introduction presents my name, a short description and my photograph. Two links invite visitors to view my selected work or read about me. This first section gives a quick overview before presenting more detailed information.

The selected work section contains three academic projects: a personal website, a programming project about binary trees and a control systems project. Each project includes an illustration, a description and the technologies used. Visitors can expand the project notes to read about the task, the approach and what I learned.

The skills section groups my tools into web development, programming and systems. The About section explains my academic interests and how I learn through practical projects. More about me adds my Computer Engineering studies, Advanced English certificate and volunteering with the Scout movement.

The final section explains my approach to a project in three steps: understanding, building and improving. The footer includes links to return to the work or the top of the page, together with a sharing button. On smaller screens, the same information appears in one column and keeps the same reading order.

3. Visual design
The website has a simple, light appearance inspired by personal developer portfolios, including the Dídac Gros portfolio provided as a reference. I chose this format to present myself through my projects and interests. The design uses open sections, clear headings and space between elements to make the page easy to explore.

The main background is warm off-white (#F7F5F0). A soft grey background (#EEECE5) separates supporting sections, while dark text (#232522) keeps the content readable. Secondary text uses grey-green (#626760). Burnt orange (#B94B2B) highlights buttons, selected words and small details. Thin lines help separate the sections without adding many boxes.

The typography uses Arial, with Helvetica and sans-serif as alternatives. Large, bold headings introduce the main ideas, while smaller labels identify sections and project categories. Body text has comfortable line spacing and limited line lengths so longer paragraphs remain easy to read.

On desktop, the introduction places my photograph beside the text. The portrait has rounded corners and a vertical crop. Project illustrations also appear beside their descriptions, and the skills are arranged in three columns. On mobile, these elements stack vertically to fit the available space.

The project illustrations help explain the different subjects and give each project a visual identity. Buttons, links and expandable notes provide simple interaction. Clear focus outlines support keyboard navigation, and the page respects reduced-motion preferences. These decisions create a consistent portfolio that feels personal and remains practical across screen sizes.
